# Intranett – Norsk Kylling

En enkel intranettside laget med HTML, CSS og JavaScript.

## Filene

| Fil          | Hva den gjør                                         |
|--------------|------------------------------------------------------|
| `index.html` | **Innholdet** – tekst, nyheter, lenker, kontakter    |
| `style.css`  | **Utseendet** – farger, skrift og oppsett            |
| `script.js`  | **Oppførselen** – hilsen etter klokkeslett og søk    |

## Slik åpner du siden

1. Last ned filene (på GitHub: grønn knapp **Code → Download ZIP**, og pakk ut).
2. Dobbeltklikk på `index.html` – den åpnes i nettleseren.

## Slik endrer du den

- **Ny nyhet:** kopier en `<article> ... </article>`-blokk i `index.html` og endre teksten.
- **Ny kontakt:** kopier en `<tr> ... </tr>`-linje i `index.html`.
- **Lenker:** bytt ut `href="#"` med ekte nettadresser.
- **Farger:** endre verdiene øverst i `style.css`.

Lagre filen og trykk F5 i nettleseren for å se endringen.
